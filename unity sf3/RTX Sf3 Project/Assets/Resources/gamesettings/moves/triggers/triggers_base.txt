####################################################################################
#  Механика срабатывания триггеров такова:
#  Получаем эвент, пробегаем по всем триггерам с ним
#  Проверяем их условия ПО ОЧЕРЕДИ, и если они выполнились, то
#  Запускаем все экшены, после чего идём к следующему триггеру
#  
#  Таким образом, несколько правил работы с триггерами:
#  1. УСЛОВИЯ ДОЛЖНЫ ИДТИ В ПОРЯДКЕ ЧАСТОТЫ ИХ ВЫПОЛНЕНИЯ (чтобы отсечь лишние проверки триггеров). Например, событие блока случается в 50% случаев (допустим) - значит, ставим его самой первой строчкой.
#  2. ТРИГГЕР НАДО ПИСАТЬ С УЧЁТОМ ТОГО, ЧТО ВСЕ ДРУГИЕ ТРИГГЕРЫ, СРАБАТЫВАЮЩИЕ НА ЭТОТ ЭВЕНТ УЖЕ МОГЛИ ЧТО-ТО ПОМЕНЯТЬ. Соответственно, лучше всего пользоваться шаблонами приоритета (пока их нет :) ) - всё, что изменяет 
#     запускается на эвент Hit и чему важен параметр удара Critical, должно идти первым, а хитэффекты - последними (потому что им уже не нужно что-то менять, только отреагировать)
#
#  UPD: Вскоре стэк триггеров будет срабатывать в пределах одного эвента для всех моделек
